Dry run

On by default. Cycles are labeled as simulations and nothing is submitted. Unchecking this records later cycles as live. It does not apply to jobs or send email.

Auto-apply

Off unless you check this box. It is separate from dry run. This build does not submit applications or send messages even when both dry run is off and this box is checked. Eligibility on a match is not an application.

Commute radius

Each person’s commute review minutes are the radius. On-site and hybrid jobs farther than that limit are skipped on the next cycle. Jobs with no location are excluded. Edit the minutes on the person’s profile. Adzuna’s distance_miles setting is sent to that API in kilometres. USAJOBS radius stays in miles.
