Dry run

On by default. Cycles are labeled as simulations and nothing is submitted. Unchecking this records later cycles as live. It does not apply to jobs or send email.

Auto-apply

Off unless you check this box. It is separate from dry run. This build does not submit applications or send messages even when both dry run is off and this box is checked. Eligibility on a match is not an application.

HigherEdJobs email alerts

Optional. Create a saved-search alert on HigherEdJobs and deliver it to a dedicated mailbox. These fields are stored in config/secrets.yaml. The username and password are masked and are not written into the page. Leave them blank to keep the saved values.

Setup: on HigherEdJobs, save the search you want and turn on the email alert. Create a mailbox that receives only those alerts (or a forward rule into one). Put that mailbox here, then run a cycle. The source badge is not configured until host, username, and password are set, ok when new listings are stored, and no new alerts when the mailbox has nothing new.

Each person’s commute review minutes are the radius. On-site and hybrid jobs farther than that limit are skipped on the next cycle. Jobs with no location are excluded.
